# 수출입 해상운임 대시보드

부산/인천 수입 운임 데이터를 기반으로 만든 대시보드입니다. (2026년 1월~7월 데이터 기준)

## 버전 안내

### v1 — 표 형식
🔗 [바로가기](https://judyloobylee-ops.github.io/freight-dashboard/)

- 전체 운임 리스트를 표 형태로 확인
- 기간 / 출발항 / 지역 / 선사 / 도착지 검색 필터
- 표에서 항로(도착지+선사) 클릭 시 오른쪽에 운임 추이 그래프 표시

### v2 — 대표님 대시보드 스타일
🔗 [바로가기](https://judyloobylee-ops.github.io/freight-dashboard/v2/)

- 왼쪽에서 지역 → 도시 선택
- 출발항(부산/인천), 컨테이너(20ft/40ft) 토글
- 초기·최신 평균 운임, 최저가·최고가 선사 요약 카드
- 선사별 선임 추이 그래프
- 선사별 최신 운임 상세 카드 (20ft/40ft, 비고 포함)

## 데이터 업데이트
매월 상반월/하반월 운임 엑셀 자료가 나오면 Claude로 다시 만들어서 해당 파일(`index.html` 또는 `v2/index.html`)을 덮어쓰기하면 됩니다.
